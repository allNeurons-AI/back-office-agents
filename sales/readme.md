# Sales Skills

## `/sales:call-prep` — Call Prep

On demand, before an external call: identifies the account and who owns it, pulls relationship history from CRM, email, chat, and docs, checks recent public signal on the company (funding, launches, leadership moves), reads any known competitive context, and writes a single 1-2 page Word document brief — who's on the call, where things stand, what's happening with them right now, how to position, a stated objective with discovery questions for this specific call, and a sourced citation list.

Never sends anything. Auto-detects whatever's connected (Google/Microsoft calendar+email, Slack/Teams, CRM, SharePoint/Drive, ticketing) so it works the same in any org.
